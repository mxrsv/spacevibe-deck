# Mobile companion direction mock (2026-11-05)

A static HTML mock of the iPhone companion's home directions. It lives on this branch only and is never merged into `main`.

- **Open it:** open `index.html` in a browser. The page has toggles for Dark/Light, Worst case and the frame size.
- **The owner's pick:** E, every desktop's tree with the waiting panes pinned on top. Spec: `docs/specs/2026-11-04-mobile-companion.md`, decisions 25–27 and MOB16 (on `main`).
- **The token layer:** `tokens.css` is a snapshot of the 2026-11-04 Deck recipe mock. `mobile.css` adds the iPhone layer.
- **Icons:** the icons are Hugeicons as stand-ins; the app uses SF Symbols (decision 26).
