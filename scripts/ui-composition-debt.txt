# The UI composition ledger: off-recipe values that predate the ratchet, one `path rule count`
# line per file and rule. Two suites count against it:
#
# - scripts/ui-composition-gate.test.ts reads the `.tsx` and `.ts` lines. Rules: `small-text` and
#   `chip-like` (spec 2026-11-03-ui-composition, CMP-5 to CMP-7, CMP-10), and `arbitrary`,
#   `spacing-step`, `weight`, `shadow`, `ring` and `phosphor` (spec 2026-11-05-ui-recipes-ratchet,
#   RCP-26).
# - src/styles/composition-rules.test.ts reads the `.css` lines. Rules: `radius`, `height`,
#   `spacing`, `focus`, `state-bg`, `shadow` and `weight` (RCP-25). Its three older checks (a
#   size under 12, a focus outline, a divider line) have no line here: they stay at zero.
#
# A file may hold at most its count, and a file not listed holds no hit. A count only falls:
# lower it when you move a value onto its recipe, and remove the line at zero. Never raise one or
# add a file (AC-5). A value that must stay off its scale carries `ui-scale: <reason>` on the line
# above instead, and the change that adds one says so in its PR (RCP-27, R9).
#
# Seeded on 2026-11-05 with the tree's counts, so both suites were green on day one.
